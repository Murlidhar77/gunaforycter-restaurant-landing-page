# Gunaforycter — Restaurant Menu Landing Page

A restaurant-inspired landing page I built using HTML and CSS. I wanted to create a dark, modern design with food cards, warm orange accents, and a dedicated section for the chef's special.

This project helped me practice turning a visual design into a complete webpage while improving my CSS layout and styling skills.

## Features

- **Food menu cards:** Displays four food and drink items with images, descriptions, prices, and a "New" label.
- **Chef's special section:** A separate feature section with a large image, description, and an Explore Menu button.
- **Hover effects:** Food cards have smooth transitions, a subtle glow, and a lift effect when hovered over.
- **Styled footer:** Includes navigation links, copyright text, and social media icons.
- **Dark visual theme:** Uses dark backgrounds, warm orange accents, and contrasting text to create a restaurant-inspired look.

## Technologies Used

- HTML5
- CSS3

## What I Learned

While building this project, I practiced:

- Structuring a webpage using semantic HTML elements such as `header`, `section`, `nav`, and `footer`.
- Using CSS Flexbox and Grid to arrange content and align elements.
- Styling cards with borders, rounded corners, spacing, and background colors.
- Creating hover effects and smooth transitions using CSS.
- Working with images, typography, and consistent colors to build a cohesive design.
- Organizing styles with CSS classes and applying them to different sections of a webpage.

2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
